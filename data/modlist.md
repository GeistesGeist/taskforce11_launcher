# Task Force 11 — Modliste

**Preset:** `TaskForce11_Realism_V4` · **Mods:** 50 · **Stand:** 2026-08-30

Diese Liste ist die Referenz für die Pflichtmods der Einheit. Sie wird aus dem
Arma-3-Launcher-Preset unter [presets/TaskForce11_Realism_V4.html](presets/TaskForce11_Realism_V4.html)

TF11 Launcher zur Laufzeit liest.

## Übernehmen ohne Launcher

Preset-Datei herunterladen und im Arma 3 Launcher auf das Fenster ziehen
(oder: MODS → PRESET → IMPORT).

## Liste aktualisieren

Neues Preset aus dem Arma 3 Launcher exportieren, nach `data/presets/` legen und
das Konvertierungsskript laufen lassen — es schreibt `workshop.json` und diese
Datei neu:

```powershell
powershell -ExecutionPolicy Bypass -File tools/Convert-Preset.ps1 -PresetPath "data/presets/<neues-preset>.html"
```

Danach committen und pushen. Der Launcher zieht die neue Liste beim nächsten
Start automatisch — es braucht kein neues Launcher-Release dafür.
