# TaskForce11 Launcher

Offizieller Launcher für **[Task Force 11](https://www.taskforce11.de/)** — Kommando
Spezialkräfte der Marine.

Der Launcher übernimmt für dich:

- Prüft, ob alle benötigten Arma 3 Mods installiert sind, und abonniert/lädt fehlende automatisch über den Steam Workshop nach
- Startet Arma 3 direkt mit optimierten Einstellungen und verbindet dich mit dem Server
- Verbindet dich auf Klick mit dem TeamSpeak-Server
- Aktualisiert sich von selbst

## Download

Neueste Version: **[github.com/GeistesGeist/taskforce11_launcher/releases/latest](https://github.com/GeistesGeist/taskforce11_launcher/releases/latest)**

Dort `TaskForce11Launcher-win-Setup.exe` herunterladen und ausführen. Das war's — die
restlichen Dateien auf der Release-Seite brauchst du nicht.

Beim ersten Start meldet sich Windows mit „Der Computer wurde durch Windows geschützt".
Auf *Weitere Informationen* und dann *Trotzdem ausführen* klicken.

## Benutzung

1. Steam starten und einloggen
2. Launcher öffnen
3. Auf **START** klicken
   - Fehlende Mods werden automatisch abonniert und heruntergeladen
   - Arma 3 startet und verbindet automatisch mit dem Server
4. Fertig — viel Spaß!

Solange Arma 3 läuft, zeigt der Button „LÄUFT" an.

Unten links siehst du den Online-Status des Servers samt Spielerzahl und den nächsten
Missionstermin, oben rechts deinen eingeloggten Steam-Account.

Über **MODS** siehst du, wie es um jeden einzelnen Mod steht. Der Link-Knopf führt zur
Workshop-Seite, der ↻-Knopf löscht einen Mod und lädt ihn komplett neu — der Weg, wenn
ein Mod sich im Spiel verhält, als wären die Dateien beschädigt.

Der Mikrofon-Knopf verbindet deinen TeamSpeak mit dem Einheitsserver.

## Einstellungen

Über das Zahnrad-Symbol oben rechts erreichst du die Einstellungen, falls Arma 3 oder
TeamSpeak z. B. nicht automatisch gefunden wurden — dort lassen sich die Pfade manuell
setzen.

## Voraussetzungen

- Windows 10/11 (64-bit)
- [Steam](https://store.steampowered.com/) mit Arma 3, installiert und eingeloggt
- [TeamSpeak 3](https://www.teamspeak.com/) für den TS-Knopf

## Probleme?

Wende dich an die Einheitsleitung von Task Force 11 — oder melde dich im
[Discord](https://discord.gg/74cPDMcyaU).

Hilfreich ist dabei der Verlauf: im Launcher auf das Uhr-Symbol klicken, Text
kopieren und mitschicken.
